# Interface preview

A static, browser-viewable re-creation of the React Native screens so the
NOCTURNE design system can be reviewed without installing an APK.

Open `index.html`. Seven panels: Phone Home, Detail, Player, Pairing; Android TV
Home, Activation, Search.

This is a *preview*, not the app. The shipping implementation is in `../mobile/`
(React Native 0.76.5 + TypeScript) and shares the same tokens
(`mobile/src/theme/index.tsx`). Artwork and titles here are placeholders.
